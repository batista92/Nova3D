# Nova3D

3D rendering and world toolkit for MonoGame.

The package provides rendering, PBR materials, CSM, instancing, terrain,
vegetation, streaming, glTF/GLB assets, profiling and debug rendering. It uses
MonoGame types directly and also provides input actions, audio coordination and
versioned local persistence. It does not depend on game code,
`Nova3D.Benchmarks`, BEPU or Gum.
