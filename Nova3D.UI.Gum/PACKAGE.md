# Nova3D.UI.Gum

Optional Gum lifecycle, scaling, input-routing and diagnostics integration for
Nova3D games. Games use Gum Forms controls directly; this package does not
duplicate the Gum widget API.

Includes `GumUiHost`, screen navigation, change-only HUD bindings, pooled
notifications, world-to-screen markers and V3 theme/font policies. Screen roots
and their children remain standard Gum Forms controls.

Also includes unified keyboard/gamepad back navigation and baseline text scale,
minimum hit-target, contrast and reduced-motion preferences.

See `Docs/ui.md` in the Nova3D repository for setup and ownership rules.
